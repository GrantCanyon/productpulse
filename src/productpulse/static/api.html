Две независимые оси времени

start включается, end не включается: это время события occurred_at. as_of включает только квитанции с received_at ≤ as_of. Дата события может быть позже момента знания — она не отсекается скрытым правилом.

Даты периода: 2026-01-05 (полночь UTC) или ISO 8601 с поясом. Момент знания обязательно с поясом: 2026-03-09T00:00:00Z. Без as_of используются все известные доставки.

Статусы доставки

accepted — первое принятое событие; duplicate — эквивалентный повтор; conflict — уже существующий ID с другим содержимым; invalid — неверная схема или JSON. Первое принятое содержимое не заменяется.

Семантические исключения в снимке отделены от карантина. Например, missing_predecessor может исчезнуть после доставки пропущенного бронирования.

Область фильтров и ошибки

Показатели, журнал, воронка и когорты используют период и сегмент. Качество доставки относится ко всей базе в выбранном срезе. Семантические исключения относятся к обработанной истории до end. Счётчики качества не обязаны совпадать с размером журнала.

Ответ 400 — недопустимый диапазон, дата или статус; 422 — пропущенные параметры или недопустимая пагинация; 503 — база недоступна. Сведения о подключении в ответ не включаются.

API не содержит операций записи и аутентификации. Предназначен для локальной демонстрации синтетических данных. Исходные квитанции видны каждому, кто получил доступ к порту.

Справочник работает без CDN и встроенных скриптов. Интерактивные Swagger UI и ReDoc отключены, чтобы сохранить строгую политику ресурсов.
