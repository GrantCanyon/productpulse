## Состояние

- Подготовленные до продолжения 17 сценариев: исходный запуск упал из-за отсутствия `productpulse.store`; после реализации хранилища и проектора — 17/17.

- Интерфейсы: сначала отсутствующий API, затем 30/30; PostgreSQL также прошёл полный набор.
- Решение тимлида: независимые оси времени. Регрессия с событием 10 января, полученным 6 января и известным 7 января сначала дала 0 вместо 10000; после исправления — 31/31 PostgreSQL.

- Панель подключена к настоящим данным: UTC-фильтры, сравнение моментов знания, график, воронка, когорты, качество, пагинация, цепочки исходных квитанций и CSV.
- Демо seed27/240 пользователей/8 недель: 1985 доставок, 301 оплата, 38 отмен, 6027200 центов чистой стоимости. Независимая сверка `reconciled=true`.

## Зафиксированные решения

- Первый принятый `event_id` побеждает; исправления под тем же ID — конфликт, а не UPDATE.
- `as_of` отбирает только `received_at`, `start/end` — `occurred_at`. Calendar observed/mature относятся к `end`, не к полноте доставки.
- `quality` и семантические исключения имеют явно подписанную глобальную область; область источников и отпечатка проходит независимое ревью.
- При одинаковом времени события этапы упорядочиваются по политике пути, затем по ID.
- FastAPI Swagger/ReDoc отключены; `/docs` локальный, `/openapi.json` сохраняется. CSP не ослаблялась.
- Совместное окружение не изменялось. Предупреждение Starlette о будущем переходе с httpx на httpx2 сохраняется в результатах, не подавляется.

## Что осталось

Независимое ревью семантики и UI; окончательные проверки, реальные замеры, проверка упаковки/контейнеров по доступным инструментам, исправления по доказательным регрессиям. Публикацию выполняет тимлид. Непроверенное не объявляется выполненным.

## Исправления независимого ревью

- Unicode-суррогат и переполнение UTC подтверждены RED; точечная валидация и ValueError восстановили quarantine без потери соседей.
- PostgreSQL не принимает NUL в TEXT. Исходная строка теперь хранится как ASCII JSON-обёртка `stored_raw_json`; API декодирует `raw_json`. Подтверждены roundtrip NUL/суррогата, SHA-256 и запрет некорректного source до записи.
- Чужой сегмент больше не меняет fingerprint и added_event_ids: contributing lineage отделён от context_event_ids. Регрессия сначала воспроизвела ошибку, затем прошла.
- После этих исправлений весь набор PostgreSQL: 41 passed, 11,15 с. Старую demo.db сохраняем; новая схема проверяется отдельно и используется demo-v2.db.
