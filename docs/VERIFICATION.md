# Проверки и ограничения

Проверки выполнялись локально на Windows, Python 3.12, SQLite и PostgreSQL 17.11. Версии Python-пакетов зафиксированы в `constraints.txt`.

## Уже выполнено

- Полный набор из 31 теста после исправления двух осей времени: PostgreSQL — **31 passed**, 6,40 с.
- SQLite после того же исправления — **31 passed**, 4,96 с.
- После локализации справочника — **6 passed** для интерфейсов; полный итог будет обновлён после независимого ревью.
- `ruff check src tests`: без замечаний; форматирование выполнено.
- Реальный CLI-демо на SQLite: seed27, users240, weeks8, 1985 доставок, **6,191 с** на генерацию+загрузку+сверку. 301 оплата, 38 отмен, net6027200 центов; контрольный журнал совпал.
- Приложение запущено локально для независимого визуального ревью.

Единственное наблюдаемое предупреждение тестовой зависимости: Starlette объявляет устаревающим использование `httpx` в TestClient и рекомендует `httpx2`. Текущий набор проходит. Общее окружение не изменялось ради устранения предупреждения.

CI-конфигурация предоставлена, но удалённый CI ещё не запускался. Dockerfile и compose предоставлены, но контейнерная сборка не запускалась. Нагрузочные числа на 10k/100k доставок и итог визуального ревью будут внесены только после реальных запусков. Нельзя выводить обещания производительности из малого демо.
