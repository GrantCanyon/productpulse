У восстановленной оплаты `session-00269-paid` квитанция #1818 получена 25 февраля, предшественники #1939–1941 — 28 февраля. Источники доступны из кнопки «После». Ошибок и предупреждений консоли не наблюдалось.

Отдельно проверены huge offset, крайние годы 0001/9999 и переход недели в полночь/через микросекунду. Независимый проверяющий подтвердил 5 календарных случаев на обеих базах через прямой отчёт и HTTP.

Единственное предупреждение тестовой зависимости: Starlette объявляет устаревающим использование `httpx` в TestClient и рекомендует `httpx2`. Предупреждение не подавляется; набор проходит. Совместное окружение не менялось.

## Ограничения результатов

Малый demo-замер — не нагрузочный тест и не обещание производительности. Проектор загружает историю в память, сортирует и пересчитывает её; сравнение хранит один набор доставок и две проекции. Замеры на 10k/100k доставок пока не выполнены. Промышленное развёртывание, отказоустойчивость и доступ извне в область этих проверок не входят.

CSV пересчитывается по применённым фильтрам; это не сохранённый снимок панели. Даже фиксированный as_of воспроизводим при неизменной истории, а разрешённая лабораторная загрузка задним числом может её дополнить.

## Первый контейнерный запуск этапа ревизии

GitHub Actions [41363589183](https://github.com/GrantCanyon/productpulse/actions/runs/41363589183), коммит `39f26e5`: SQLite и PostgreSQL прошли. Compose собрал образ, дождался базы и сверил демо; первый HTTP-запрос завершился `Connection reset by peer` сразу после состояния контейнера Started. В диагностике ещё не было строки готовности приложения; завершение проверки через 21 мс после Started было преждевременным.

Ожидание заменено на ограниченный 60 секундами цикл `urllib` с монотонными часами и проверкой HTTP 200 + JSON status=ok. Временные reset/refused/HTTP503 допускаются только внутри этого ожидания. Постоянный сбой завершает задание ненулевым кодом и сохраняет диагностику Compose. Тесты реального локального сервера проверяют два первоначальных разрыва соединения с последующим успехом и постоянный HTTP503 с ограниченным временем отказа. Успех нового удалённого запуска пока не утверждается.
